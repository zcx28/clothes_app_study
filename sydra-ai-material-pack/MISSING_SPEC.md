# 缺失规格与实现边界

## 仍未提供的生产能力

以下内容没有正式后端、接口契约、生产账号或第三方配置，任何 AI 都不得声称已经完成线上接入：

- 真实微信登录、手机号授权、Token、刷新与登出。
- 微信/支付宝支付 SDK、商户号、签名、回调、订单核验和支付安全。
- 商品、价格、库存、兼容规则、购物车、订单、物流、售后的服务端 API。
- 数据库、迁移、对象存储、凭证上传、客服消息服务。
- 服务器环境、域名、HTTPS 证书、密钥管理、监控、备份和部署流水线。
- 法务确认的用户协议、隐私政策正文及版本管理。
- 生产级分类树、SKU、库存、运费、优惠、退款和退货业务规则。

## 图片能证明但仍只是本地原型的状态

V2 图片证明了登录失败、搜索、确认订单、支付结果、取消订单、退款进度、地址保存、会员、帮助和客服等 UI/交互状态。它们可以用本地确定性状态机实现和测试，但不能被描述为真实服务已完成。

## 资料没有充分证明的内容

- 首页独立主题详情：V2 只证明 CTA 去选购，不应另造页面。
- 完整法务正文与协议生效流程。
- 配置器真实组件兼容性和库存校验规则。
- 真实物流数据源和承运商接口。
- 凭证文件格式、大小、数量、上传协议和审核规则。
- 退款到账渠道、时效、异常处理和财务对账。
- 客服账号体系、消息同步、离线消息与人工接入。

## 推荐处理

- 前端演示：使用明确命名为 `Fake`、`Preview` 或 `LocalPrototype` 的确定性数据源。
- 调试中断：显示“仅本地原型/规格待补充”，并列出缺失项。
- 正式接入前：先确认 OpenAPI/JSON Schema、错误模型、鉴权边界、幂等策略和测试环境。
- 不建立无法替换的假 URL，不把测试数据伪装成线上数据，不提交密钥。

## 后端与服务器说明

本素材包没有后端代码，也没有“运行到服务器”的部署代码。这是有意的边界，不是遗漏：当前证据不足以定义真实登录、支付、库存、订单和售后服务。后端工作应从 API 契约、错误模型、鉴权边界、数据模型和迁移开始，并由产品/业务方确认规则后实施。
